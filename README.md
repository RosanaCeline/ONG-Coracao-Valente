# ❤️ Coração Valente

Plataforma web desenvolvida para a ONG **Coração Valente**, localizada em Tianguá (CE), com o objetivo de fortalecer sua presença digital e ampliar o alcance de suas ações sociais junto à comunidade.

---

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte da disciplina de **Projeto Social** do curso de **Ciência da Computação**, com foco em **extensão acadêmica** e impacto social real.

A proposta é conectar tecnologia e sociedade, criando uma solução digital que:

- Amplie a visibilidade da ONG  
- Facilite o contato com a comunidade  
- Apoie ações sociais e voluntariado  
- Fortaleça o vínculo entre academia e sociedade  

---

## 🎯 Objetivo

Desenvolver uma **landing page moderna e funcional** que represente a identidade da ONG e sirva como ponto central de comunicação com o público.

---

## 🚀 Tecnologias utilizadas

- React.js  
- CSS Modules  
- Lucide React (ícones)  
- Vite (ambiente de desenvolvimento)  

---

## 🧩 Estrutura do projeto

```bash
src/
 ├── components/      # Componentes reutilizáveis (Button, Card, etc.)
 ├── pages/           # Páginas da aplicação
 ├── routes/          # Configuração de rotas
 ├── assets/          # Imagens e recursos estáticos
 ├── App.jsx          # Componente principal
 └── main.jsx         # Ponto de entrada
````

## 🤝 Impacto social

A ONG **Coração Valente** desempenha um papel fundamental na comunidade de Tianguá. Este projeto busca:

* Dar mais visibilidade às ações sociais
* Facilitar o engajamento de voluntários
* Apoiar iniciativas locais
* Promover inclusão e apoio comunitário
